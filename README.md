🛠️ Building Luxy

You will need:

Node.js v22+

Yarn

Windows 10/11

1. Clone the repository
git clone https://github.com/BoltySoft/Luxy
cd Luxy

2. Install dependencies
yarn

3. Start Luxy in development mode
yarn dev


(Electron + Renderer hot reload enabled)

4. Build for production
yarn build


This generates the optimized build + installer.
